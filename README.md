# 围脖 v1

纯 HTML + CSS + JavaScript 实现的迷你微博（"围脖"），数据通过 **Local Storage** 保存在本地浏览器中。

## 功能

- 发布围脖（140 字限制、实时字数进度条、Ctrl/⌘ + Enter 快捷发布）
- 时间流查看：全部 / 热门（按点赞排序）
- 点赞（❤，本地计数、防重复）
- 话题标签：发布时用 `#话题#` 包裹，点击标签或右栏"此刻热议"可筛选
- 顶部搜索：按内容与话题关键词过滤
- 左侧个人卡片：发布数 / 被望数 / 话题数实时统计

## 使用

无需安装任何依赖，直接用浏览器打开 `index.html` 即可；或本地起一个静态服务：

```bash
npx serve .
# 或
python -m http.server 8000
```

## 数据说明

- 存储键：`weibo_posts_v1`（浏览器 Local Storage）
- 清除浏览器站点数据即可重置；首次访问会预置 3 条示例围脖

## 目录结构

```
├── index.html      # 页面结构（顶部导航 + 三栏布局）
├── css/style.css   # 渐变紫粉配色样式
└── js/app.js       # 全部逻辑（渲染 / 发布 / 点赞 / 筛选 / 存储）
```
